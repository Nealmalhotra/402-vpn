402-VPN

Pay-per-minute HTTP proxy for AI agents. Pay with USDC, get a bearer token, proxy requests through regional exit nodes.

How it works

  1. Call POST /session/create — x402 auto-charges your wallet in USDC
  2. Get a bearer token + session ID
  3. Proxy requests through POST /fetch using the token
  4. Top up anytime with POST /session/:id/topup

Pricing

$0.001 / minute

Minimum 10 minutes ($0.01) per session. Paid in USDC on Base Sepoliatestnet

Quick start

npm install @x402/fetch @x402/evm viem
// Create a paid session
import { wrapFetchWithPayment, x402Client } from "@x402/fetch";
import { ExactEvmScheme } from "@x402/evm/exact/client";
import { privateKeyToAccount } from "viem/accounts";

const account = privateKeyToAccount(process.env.EVM_PRIVATE_KEY);
const client = new x402Client().register("eip155:*", new ExactEvmScheme(account));
const pay = wrapFetchWithPayment(fetch, client);

// This auto-pays USDC and returns your session
const res = await pay("https://YOUR_DOMAIN/session/create", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ region: "us-west", minutes: 10, mode: "proxy" }),
});
const { token } = await res.json();

// Proxy requests (free while session is active)
const result = await fetch("https://YOUR_DOMAIN/fetch", {
  method: "POST",
  headers: { "Content-Type": "application/json", Authorization: \`Bearer \${token}\` },
  body: JSON.stringify({ url: "https://example.com", method: "GET" }),
});
const { status, headers, body } = await result.json();
